# Прогноз продаж декоративных птиц

В [ноутбуке](dz2.ipynb) проведено сравнение четырёх моделей на продажах товара **84879 - ASSORTED COLOUR BIRD ORNAMENT** из Online Retail. Использован дневной ряд из ДЗ1. В нём 373 полных дня, из которых получаются 52 полные недели и 12 полных месяцев. Покупки прибавляются, возвраты вычитаются в день оформления.

## Условия сравнения

Для дней наивный прогноз повторяет последнюю неделю, для недель и месяцев берёт последнее значение. Простое экспоненциальное сглаживание оценивает текущий уровень продаж. Бустинг использует прошлые продажи и скользящее среднее, а для дневного ряда ещё и день недели. При прогнозе на несколько шагов он подставляет в историю свои предыдущие прогнозы.

Для недель и месяцев дополнительно использована модель Холта. Она учитывает линейный тренд. Для дней использована модель Холта-Уинтерса с сезонностью периода 7.

Для проверки использованы последние 28 дней, 8 недель и 4 месяца. Для каждой даты модель видит только те продажи, которые были известны за нужное число шагов до неё. Внутри частоты даты проверки одинаковы на всех горизонтах. Ошибка на горизонте 7 относится к седьмому шагу прогноза. Параметры бустинга одинаковы во всех экспериментах, коэффициенты сглаживания оцениваются по обучению.

## Результаты

Лучшие модели выбраны по MAE - средней абсолютной ошибке в штуках. В таблице показаны результаты по всем зарегистрированным продажам.

| Частота | Горизонт | Лучшая модель по MAE | MAE, шт. | WAPE, % |
|---|---|---|---:|---:|
| День | 1 день | Бустинг | 88,3 | 60,1 |
| День | 7 дней | Бустинг | 92,1 | 62,7 |
| День | 31 день | Холт-Уинтерс | 94,9 | 64,6 |
| День | 61 день | Бустинг | 96,1 | 65,4 |
| Неделя | 1 неделя | Холт | 249,8 | 24,8 |
| Неделя | 4 недели | Холт | 293,1 | 29,1 |
| Неделя | 8 недель | Холт | 291,7 | 29,0 |
| Месяц | 1 месяц | Сглаживание | 1 831,1 | 41,6 |
| Месяц | 2 месяца | Холт | 1 943,2 | 44,2 |

- На недельных данных Холт снизил MAE относительно наивного прогноза примерно на 17%, 26% и 29% на горизонтах 1, 4 и 8 недель. По RMSE на одну неделю немного лучше наивный прогноз, 373 штуки против 378.
- На два месяца результаты Холта и сглаживания близки, 1 943 и 1 951 штука. Разница около 0,4% при четырёх проверочных месяцах даёт мало оснований для устойчивого выбора.
- Ошибка с ростом горизонта меняется немонотонно. В каждой группе оценивается отдельный шаг, а проверочных дат мало. При сравнении частот учитывается, что периоды проверки охватывают разные даты.

## Почему дневная ошибка высокая

У бустинга на один шаг пять дат дают 50,1% суммы абсолютных ошибок. Например, 2 декабря объём продаж составил 504 штуки при прогнозе 115, а 18 ноября - 368 при прогнозе 98. В среднем модель прогнозирует 106 штук в день при фактических 147.

Есть ограничение выбранной простой настройки модели. Во всех 49 субботах обучения первого прогноза на один день продажи нулевые, но на субботах проверки бустинг прогнозирует 36-47 штук. Недельный ритм усвоен лишь частично. Эти четыре дня дают 6,8% суммы абсолютных ошибок.

Объём продаж за 28 проверочных дней составил 4 112 штук, сумма абсолютных ошибок составила 2 471 штуку. Отсюда WAPE около 60%. Ошибка существенная. Бустинг снизил MAE относительно сезонного наивного прогноза на 37%, но его точность для ежедневного планирования остаётся ограниченной. Величина ошибки связана и с колебаниями продаж, и с простыми настройками и признаками модели.

## Сохранённые результаты

[Основные прогнозы](results/forecasts.csv) содержат конечные шаги для всех 36 сочетаний модели, частоты и горизонта. В [таблице метрик](results/metrics.csv) собраны MAE, RMSE и WAPE. [Полные прогнозы](results/forecast_paths.csv) включают все промежуточные шаги и дату конца обучения.

Графики и пояснения сохранены в ноутбуке.

## Как запустить

Для запуска в Python 3.11 необходимо установить зависимости командой `python -m pip install -r requirements.txt`. Затем требуется открыть `dz2.ipynb` в Jupyter или VS Code и выполнить ячейки сверху вниз. Подготовленный ряд уже лежит в [data/daily_sales.csv](data/daily_sales.csv). Ноутбук заново рассчитает таблицы и построит графики.
