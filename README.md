# Прогноз продаж декоративных птиц

В [ноутбуке](dz2.ipynb) сравниваем три модели на продажах товара **84879 — ASSORTED COLOUR BIRD ORNAMENT** из Online Retail. Взяли дневной ряд из ДЗ1. В нём 373 полных дня, из которых получаются 52 полные недели и 12 полных месяцев. Покупку прибавляем, возврат вычитаем в день оформления.

## Как сравнивали

Для дней наивный прогноз повторяет последнюю неделю, для недель и месяцев берёт последнее значение. Простое экспоненциальное сглаживание оценивает текущий уровень продаж. Градиентный бустинг использует прошлые продажи и скользящее среднее, а для дневного ряда ещё и день недели. При прогнозе на несколько шагов бустинг подставляет в историю свои предыдущие прогнозы.

Проверяли последние 28 дней, 8 недель и 4 месяца. Для каждой даты модель видит только те продажи, которые были известны за нужное число шагов до неё. Внутри частоты даты проверки одинаковы на всех горизонтах. Ошибка на горизонте 7 относится к седьмому шагу прогноза.

## Результаты

Лучшие модели выбирали по MAE — средней абсолютной ошибке в штуках. В последнем столбце значения округлены до целых.

| Частота | Лучшая модель по MAE | Горизонт и средняя ошибка |
|---|---|---|
| День | Бустинг | 1 день — 88 шт., 7 дней — 92 шт., 31 день — 97 шт., 61 день — 96 шт. |
| Неделя | Наивный прогноз | 1 неделя — 299 шт., 4 недели — 395 шт., 8 недель — 413 шт. |
| Месяц | Сглаживание | 1 месяц — 1 831 шт., 2 месяца — 1 951 шт. |

- У бустинга дневная ошибка выросла с 88 до 96 штук между самым коротким и самым длинным горизонтом. Крупные заказы трудно предугадать. Например, 9 ноября продали 1 312 штук, а по данным на 8 октября все три модели прогнозировали меньше 120.
- На недельных данных последнее значение выиграло по MAE на всех горизонтах. На четырёх неделях у сглаживания ниже RMSE (543 штуки против 561). Эта метрика сильнее учитывает крупные ошибки.
- Месячное сглаживание выиграло по MAE на обоих горизонтах. Вывод предварительный. В проверку попали всего четыре месяца, в том числе август с крупным заказом и ноябрь с ростом продаж.
- Чтобы сравнить частоты, посмотрели WAPE — сумму абсолютных ошибок относительно объёма продаж. На один шаг у лучших моделей получилось 60,1% для дня, 29,7% для недели и 41,6% для месяца. На выбранных отрезках недельный прогноз оказался точнее в процентах.

В [таблице прогнозов](results/forecasts.csv) для каждой оценки указаны конец обучения, дата прогноза, факт и прогноз. В [таблице метрик](results/metrics.csv) собраны MAE, RMSE и WAPE для всех 27 сочетаний частоты, горизонта и модели.

## Как запустить

В Python 3.11 установите зависимости командой `python -m pip install -r requirements.txt`. Откройте `dz2.ipynb` в Jupyter или VS Code и выполните ячейки сверху вниз. Подготовленный ряд уже лежит в [data/daily_sales.csv](data/daily_sales.csv). Ноутбук заново рассчитает обе таблицы и построит графики.
